## Component Breakdown (for designers & engineers)
1. Top Bar
Logo

Product name

Settings icon (optional)

2. User Snapshot Panel
Shows the most important “state of the day”:

Current date

Next meeting

Pending tasks

3. Daily Plan Card
A scrollable card summarizing the assistant‑generated plan.

4. Quick Actions Panel
Buttons for the most common workflows:

Upload notes

Summarize

Schedule

Update CRM/Sheet

Research

Payment status (optional)

5. Chat Panel
Conversational interface where the agentic assistant interacts.

6. Input Box
Simple text input with optional:

Voice input

File upload

“Ask AI” button
